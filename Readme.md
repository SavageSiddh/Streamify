# StreamHub API

A scalable REST API for a video-sharing platform built using Node.js, Express.js and MongoDB.

## Features

- JWT Authentication
- Refresh Tokens
- Video Upload
- Playlist Management
- Comments
- Likes
- Dashboard Analytics

## Tech Stack

- Node.js
- Express
- MongoDB
- Mongoose
- Cloudinary
- JWT
